# Salmar AI

A multimodal intelligence system with a hybrid Go + Python backend architecture.

## Features

- Natural language understanding and generation
- Code generation and explanation
- Image analysis and generation
- Cross-modal reasoning
- Task automation
- Adaptive user preference learning
- Unified context-aware orchestration

## Architecture

Salmar AI uses a hybrid architecture:
- **Go Backend**: Core API, service orchestration, and request handling
- **Python Services**: Specialized multimodal processing modules

## Getting Started

### Prerequisites

- Go 1.20+
- Python 3.9+
- Docker and Docker Compose (for containerized deployment)

### Installation

1. Clone the repository
2. Install Go dependencies: `go mod tidy`
3. Install Python dependencies: `pip install -r requirements.txt`
4. Configure environment variables (see `.env.example`)
5. Start the services: `docker-compose up`
